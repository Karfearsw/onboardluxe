VA Skip-Trace SOP: Free-Source Enrichment

VA · SDR · Agent 10 min read Knowledge Check (4 questions · pass 4/4)

What This Workflow Does

Roughly a third of our leads have no usable phone number — the dialer can't call them. This SOP turns "no phone" leads into callable leads using only free public sources and manual people-search. Every lead leaves the workflow with a verified owner name, at least one phone where one exists, every source logged, and a confidence score — or a clear status explaining why not.

Pace & Quality

Plan 12–20 leads per hour once practiced (3–5 minutes per lead), time-boxed to 8 minutes max per lead. Quality beats speed: one wrong number wastes more dialer time than skipping a lead costs.

Golden Rules — No Exceptions

  1. Manual browser use only. One human, one browser, one lookup at a time. Never use scrapers, bots, scripts, or automation on people-search sites. Their terms ban it, and violations put the company at risk.
  2. Never pretend to be anyone else. No calling utilities, banks, or county offices posing as the owner. No pretexting, ever.
  3. Never use breached or hacked data. If a site looks like stolen data, close it and report it.
  4. Log every source for every number. A phone number without a recorded source is worthless — it can't be trusted, re-verified, or defended.
  5. A found number is NOT consent. Enriched numbers go to the manual-call queue only. Never text a skip-traced number — cold texts to these numbers carry $500–$1,500 per-message liability.
  6. Respect opt-outs instantly. If a person says stop, or a number hits a DNC list, flag do_not_contact immediately and move on.

Triage: Which Leads First

Work strictly top-down. Highest triage score first, no cherry-picking easy leads:

  • Absentee owners (tax mailing address ≠ property address) — highest priority
  • Tax-delinquent / pre-tax-sale flags
  • Owner name already verified — just missing the phone
  • Skip entirely: test records, duplicates, or leads with no property address
Test-Record Guard

Check the flagged test-record list before enriching. Never enrich test records ("123 Test St", "999 Test Way", "E2E UiAudit", "Workflow Test"). If you spot one in the queue, flag it and skip — production holds real people only.

The 7-Step Enrichment Workflow

  1. Confirm the property & owner (assessor, 60–90 sec). Fix the address first — our list has known state-label errors. Then: MA → MassGIS L3 / MassLandRecords.com · FL → county Property Appraiser site · MI → county GIS or Detroit open parcel map · RI → town assessor site or RIGIS. Record owner name, tax mailing address, LLC-owned yes/no, assessed value. Mailing address ≠ property address = absentee flag.
  2. Pierce LLCs (if LLC-owned, 2–3 min). An LLC name is not a person you can call. FL → Sunbiz.org (free, no login) · MA → corp.sec.state.ma.us · RI → business.sos.ri.gov (searchable by address) · MI → LARA registry (resident agent; MI doesn't publish LLC members). Record every human name with the source document.
  3. Court & life-event check (2 min, highest-value step). Self-filed bankruptcy petitions (CourtListener/RECAP, Official Form 101) literally ask for contact phone/cell/email — the single best free phone source found in our research. FL eviction complaints (Palm Beach eCaseView, Orange myeclerk) show self-represented landlord phones in the plaintiff block. Obituaries → surviving heirs; probate → heirs with addresses. Never dial a deceased owner's number — flag as heir trace.
  4. License & professional check (1–2 min). MI (most of our list): LARA's published license spreadsheet includes business phone + email. National: NPPES NPI Registry for medical professionals (practice phone). FL: myfloridalicense.com gives addresses (often a distinct home address).
  5. People-search sweep (2–3 min, manual only). TruePeopleSearch → FastPeopleSearch → That'sThem → FamilyTreeNow. Search "First Last, City ST". Cross-check every number across at least 2 sites. If a site shows a CAPTCHA or rate-limit, slow down or switch sites — never bypass it.
  6. Validate candidate numbers (1 min). Format check (valid 10-digit US). Manual WhatsApp check (wa.me/1XXXXXXXXXX) — a name/photo confirms it's live and real. Never automate this. Note line type (mobile / landline / unknown).
  7. Log it (CRM or CSV fallback). One of four statuses: enriched (verified owner + ≥1 phone, confidence ≥ 50) · partial (verified owner, no phone → direct-mail list) · heir trace (owner deceased; work the heirs) · exhausted (all 7 steps attempted → waits for paid skip trace). Every number gets: lead ID · person name · phone · source(s) · confidence · line type · primary flag · DNC flag + reason · your name · date.

Confidence Scoring

Every number carries a confidence score. The dial queue gets 50+; 70+ gets called first.

Confidence Rubric
90–100 — Number on 2+ independent sources, name/city match
70–89 — Two sources with minor mismatch, or one strong source
50–69 — Single people-search hit, plausible (name/city/age)
30–49 — Weak match — use with caution
Below 30 — Do not dial. Mark for manager review.
  • Edge case — can't disambiguate a common name: use age + city + relatives from profiles. Still unsure? Mark partial — never attach a maybe-number with high confidence.
  • End-of-shift report: enriched / partial / heir trace / exhausted counts, phones found, average confidence, blockers (e.g., "Wayne County images paywalled").
  • Flag bad data, don't fix it silently: wrong addresses, duplicates, and test records get flagged to your manager, not quietly skipped.
Instant Removal Offenses

Using scrapers or bots · pretexting · texting a skip-traced number · using breached data · enriching flagged test records · sharing lead data outside the company. Any one of these ends the engagement.
